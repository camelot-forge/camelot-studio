# Code of conduct

Be civil. Disagree with the code, the design, or the evidence, not with the
person.

Harassment, discrimination, threats, and publishing someone's private
information are not accepted in issues, pull requests, discussions, or any
other project space. Maintainers may edit or remove contributions that break
this rule, and may block an account that repeats it.

Report a concern to the maintainers through the repository's private security
advisory (Security → Report a vulnerability). Reports are read privately.
